# Highland Mist is a set of four animated Instagram Story backdrops (1080 × 1920) that I coded in Processing (Python Mode) for Ansk Media. Each one is generative. The visuals are drawn entirely with code rather than filmed or designed in an editing app, and they loop continuously so they work as moving backgrounds behind text, client announcements or promotional content. The collection is inspired by the Southern Highlands: horses in paddocks, vineyards in autumn, sunsets over the ranges. Two of the pieces use a shared yellow and navy palette that ties the set to a consistent brand look. Each sketch also has a key command to export a still PNG, and the stripes sketch can record frames for video.
